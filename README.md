🧠 Modelos de Prompts Básicos para IA.
Este repositório contém modelos de prompts básicos para diferentes tarefas com Inteligência Artificial.

📌 Categorias de Prompts
Geração de Texto: Exemplos para criação de textos, respostas e resumos.

Geração de Imagem: Exemplos para criação de imagens com IA generativa.

Geração de Áudio: Exemplos para síntese de voz e narrações.

Transcrição de Áudio: Exemplos para transformar áudio em texto.

✅ Finalidade
Prompts simples, diretos e fáceis de adaptar.
Úteis para estudos, testes e primeiros projetos com IA.

🚩 Observação
Os prompts podem ser ajustados conforme a ferramenta de IA que você estiver usando (ChatGPT, DALL·E, Whisper, ElevenLabs, etc).
